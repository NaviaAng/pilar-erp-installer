# Pilar ERP · Installer

Aplikasi kasir, stok, dan pembukuan untuk toko, resto, dan UMKM dari **PT Pilar Sukses Sinergi**.
Repo ini hanya berisi **installer** dan **riwayat perubahan**. Kode sumber tidak dipublikasikan.

## Pasang

1. Jalankan `PilarErp-Setup.exe`. Tidak perlu hak administrator.
2. Installer memilih versi aplikasi sendiri: Windows 10/11 64-bit memakai versi utama; Windows 7 SP1, 8.1, atau Windows 32-bit memakai versi kompatibel
   yang butuh .NET Framework 4.8 (bila belum ada, installer menunjukkan tautan unduhnya).
3. Aplikasi diunduh dari server Pilar ERP (±90 MB, atau ±40 MB untuk Windows 7), lalu pintasan dibuat di Start Menu dan Desktop.
4. Windows bisa menampilkan peringatan SmartScreen karena installer belum ditandatangani: pilih **More info** › **Run anyway**.

Installer hanya dibutuhkan untuk PC baru. PC yang sudah terpasang memperbarui diri sendiri saat Anda menekan **Masuk**.
